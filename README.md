# จับคู่โน้ต v2

เปิด `index.html` ใน Chrome หรือ Edge แล้วเลือกสำรับ กุญแจซอล กุญแจฟา สัญลักษณ์ดนตรี หรือศัพท์อิตาเลียน

- **ปกติ** จับคู่ให้ครบ ใช้จำนวนครั้งให้น้อยที่สุด ระดับง่ายเปิดให้จำตำแหน่งก่อนเริ่ม
- **แข่งเวลา** จับคู่ให้ได้มากที่สุด การจับคู่สำเร็จเพิ่มเวลา และแจกกระดานใหม่เมื่อจับคู่ครบ
- **ฟังเสียง** ฟังเสียงจากการ์ดลำโพงแล้วจับคู่กับโน้ตบนบรรทัดห้าเส้น

หลังจบรอบจะเห็นคะแนน ความแม่นยำ เวลาที่ใช้ และการ์ดที่มักเปิดผิด ดูเหรียญสะสมจากหน้าแรกได้

## แก้ไขสำหรับการสอบ

ไฟล์เดียวแบ่งเป็นห้าโซน โซน A เก็บโน้ต สำรับ โหมด และเหรียญ โซน B เก็บค่าตั้งต้น โซน C เป็นแกนเกม
โซน D แสดงผลและเล่นเสียง และโซน E สำหรับเพิ่มความสามารถ เลือกทำหนึ่งข้อ

1. **เล่นสองคน** ผลัดกันเล่น จับคู่ได้แล้วได้คะแนนและเล่นต่อ
2. **ปุ่มช่วย** จำกัดจำนวนครั้งที่ขอให้ไฮไลต์คู่ ใช้ `Game.hintPair()`
3. **สำรับของฉัน** เพิ่มสำรับในโซน A อย่างน้อย 8 คู่
4. **โจทย์ประจำวัน** ใช้วันที่กำหนดกระดานและแยกสถิติของแต่ละวัน
5. **คัดลอกผลการเล่น** เพิ่มปุ่มคัดลอกสรุปผลภาษาไทย
6. **เหรียญของฉัน** เพิ่มเหรียญ เงื่อนไข และสีเหรียญ

เปิด **ตั้งค่า → ตรวจระบบ** หลังแก้ แล้วทดลองเล่นฟีเจอร์ที่เพิ่มด้วยตนเอง เกมเผยแพร่ได้โดยวาง
`index.html` ไว้ที่รากของสาขาที่ตั้งให้ GitHub Pages เผยแพร่
